# AMP-style layout

Use a 16:9 landscape canvas with:

- 10% header;
- top row: 24% Motivation, 48% Method Overview, 28% Key Idea;
- middle row: 62% Method/Design, 38% Experimental Results;
- bottom row: Contributions, Highlights, and a compact Project panel;
- no duplicate project footer.

Give the top row about 45% of the canvas height, the middle row about 32%, and
the bottom row only about 13%. The overview image must dominate its panel.
Remove page headers and continuous white margins from source crops before
layout.

Keep 300-800 words, every independent Gate-passing Motivation and Contribution,
up to three Highlights, one overview asset or an explicit fallback, at most
one Key Idea equation, and one readable result asset. Adapt card columns,
wrapping, and font scale to the validated semantic item count; never drop an
item only to repair layout. Preserve extra extracted results in the asset
catalog rather than shrinking them into unreadable poster thumbnails.

The visual reference is AMP's poster image. Do not copy its logo, paper text,
figures, or institutional assets.
