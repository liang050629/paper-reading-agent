# Storyline analysis rubric

Extract:

1. research problem;
2. motivation;
3. prior-work gap;
4. core hypothesis;
5. method design;
6. theory or mechanism;
7. experimental design;
8. experimental results;
9. conclusion;
10. limitations.

Prefer direct author statements. Use `inferred` only when multiple source
passages support the interpretation. Use `not_found` instead of completing a
conventional paper narrative from general knowledge.

Read abstract, introduction, related work, method, experiments, discussion,
limitations, conclusion, appendices referenced by the main text, and all
captions relevant to core claims.
