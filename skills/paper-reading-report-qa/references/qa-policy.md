# Reading report QA policy

The QA stage is evidence-first. A visually clean report fails when factual
entries lack source blocks, source-index IDs dangle, formulas lack page/bbox,
or supported Claims have no evidence.

Rendering failures include missing HTML or Markdown, missing requested PDF,
missing images, uncontrolled horizontal overflow, and text below the minimum
readability threshold.

The report may contain zero explicit limitations or zero equations when the
paper genuinely contains none. It must say so rather than inventing content.
