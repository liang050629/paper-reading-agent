# Method graph contract

Each node records a stable ID, paper order, short name, purpose, innovation,
section identity, figure references, status, and source coordinates.

Each edge records source and target node IDs, a relation, the order basis, and
source evidence. `section_order` means reading order only; it must not be
presented as a proven tensor or causal data flow.

Exclude experimental outcomes, comparisons, ablations, and limitations.
