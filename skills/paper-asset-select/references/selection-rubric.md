# Asset selection rubric

Inspect every caption and its context. Figure number contributes zero points.

Overview positives: overview, overall, framework, architecture, pipeline,
workflow, complete input-to-output flow, method-section placement, repeated
citation, and coverage of multiple method components.

Overview negatives: ablation, sensitivity, qualitative examples, dataset
samples, confusion matrices, isolated module details, result-only plots, and
missing local image data.

Visually verify the top candidates. If none summarizes the method, use a method
flow, mechanism figure, two complementary originals, equations plus HTML
connectors, or a truthful no-overview placeholder.

Select result assets only after claims are audited. Prefer the smallest set
that supports the main performance, component, efficiency, or generalization
claims.
